# JMC Launcher

🚀 **JMC Launcher** – A modern, lightweight Minecraft launcher with Fabric support and full mod management.  

Run the EXE directly on Windows — no Python needed. Configs and logs are saved in the same folder as the launcher.

---

## Features

- Launch Minecraft with **offline username support**  
- **Install / Update Fabric** automatically  
- **Mods management**: drag & drop `.jar` mods, delete, refresh, open mods folder  
- **Custom Java support**: auto-detect, custom path, JVM arguments  
- **RAM allocation** (1–16 GB)  
- **Light / Dark mode** (follows Windows theme on first run)  
- **Hidden log** saved daily in `logs/YYYY-MM-DD.log`  

---

## Quick Start

1. Download `JMC Launcher.exe` from the releases page.  
2. Place it anywhere you want; the launcher will auto-create `logs` and `config` files in the same folder.  
3. Run the EXE.  
4. Use the **Launcher tab** to enter your username and start Minecraft.  
5. Drag & drop mods in the **Mods tab**.  
6. Tweak RAM, JVM args, and Java path in **Settings** if needed.  

---

## Notes

- Windows only  
- Logs and config are stored **locally** in the same folder  
- Works offline for launching Minecraft in offline mode  
- Internet required for Fabric installation or updates
